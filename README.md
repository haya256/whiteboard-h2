# whiteboard-h2

SVGベースの軽量ホワイトボードツール。ブラウザとElectronデスクトップアプリの両方で動作します。

## 特徴

- ゼロ依存（バニラJS + SVG）
- ブラウザ・Electronどちらでも動作
- ボードを `.svg` ファイルとして保存（SVG + 埋め込みJSONで再編集可能）

## 起動

```bash
npm install      # 初回のみ
npm start        # Electron デスクトップアプリ
npm run serve    # ブラウザ版（http://localhost:8080）
```

サーバーを立てなくても、`index.html` をブラウザで直接開くだけで動作します（ビルド不要・サーバー処理なし）。
ただし自動保存（localStorage）はブラウザが「開いた場所（URL）」ごとに分けて保持するため、`file://` で開いた場合と `http://localhost:8080` で開いた場合ではボードが共有されません。別の場所で開き直すときは .svg で保存して読み込んでください。

## 動作環境

- **推奨: Google Chrome / Microsoft Edge（最新版）**。すべての機能が動作します。
- Firefox / Safari でも動作しますが、以下の機能制限があります。
  - 「開く (.svg)」「保存 (.svg)」は File System Access API を使ってフォルダの場所を記憶しますが、Firefox / Safari は非対応のため、従来のファイル選択ダイアログとダウンロードに自動で切り替わります（保存先はブラウザのダウンロードフォルダになり、フォルダの記憶はできません）。
- スマートフォン・タブレットのタッチ操作は未対応です（マウス操作を前提にしています）。
- データはサーバーに送信されません。自動保存はブラウザ内（localStorage、多くのブラウザで約 5MB）に保持され、大きな画像を多く貼ると上限に達することがあります。その場合は .svg で保存してください。

## ツールバー

用途ごとに5つのグループに分かれています。

| グループ | 内容 |
|------|------|
| ファイル | 新規 / 開く (.svg) / 保存 (.svg) |
| 編集 | 元に戻す / やり直す |
| 挿入 | 付箋 / 矩形 / 楕円 / ひし形 / テキスト / 画像 / コネクタ |
| 表示 | ズーム率 / 全体表示 / リセット |
| ヘルプ | 使い方（ウェルカム画面を開く） |

ウィンドウの幅が足りないときは、入りきらないボタンが各グループの「⋯」にまとまります（畳まれる順は 編集 → 表示 → ファイル → 挿入。各グループの左端のボタンは常に残るため、「表示」の左端にあるズーム率はいつでも確認できます）。

## 使い方

| 操作 | 方法 |
|------|------|
| 付箋を追加 | 「挿入」→「+ 付箋」 |
| テキストを追加 | 「挿入」→「T テキスト」（背景・枠なしのテキストのみのノード。追加直後に編集モードに入り、空のまま確定すると自動で削除される） |
| 移動 | ドラッグ（複数選択時は選択中の全ノードがまとめて移動） |
| サイズ変更 | 選択して四隅・辺のハンドルをドラッグ（Shift で縦横比維持）。付箋は四隅のみで常に縦横比固定。付箋の縦横比はスタイル編集から 1:1 / 3:2 を選択 |
| テキスト編集 | ダブルクリック |
| 文字の配置 | ノードを選択すると出るスタイル編集から、横（左/中央/右）と縦（上/中/下）を設定（付箋・図形の新規作成時は上下左右とも中央） |
| 削除 | クリックで選択 → Delete キー（複数選択時はまとめて削除） |
| 複数選択 | Shift+クリックで追加/解除 / Shift+空白ドラッグで矩形選択 |
| 全選択 | Ctrl+A（Mac は Cmd+A） |
| 選択解除 | Esc |
| コネクタ | 「挿入」→「→ コネクタ」→ ノードを2つクリックして接続（Esc または空白クリックで解除） |
| コネクタ削除 | コネクタをクリックして選択 → Delete キー |
| コネクタの見た目 | コネクタをクリックすると出るスタイル編集から、線種（直線/曲線/直角）・矢印の向き（なし/終点/始点/両端）・太さ・色を変更 |
| 重なり順（Z順）の変更 | Ctrl+]（Mac は Cmd+]）で前面へ、Ctrl+[ で背面へ、Shift併用（Ctrl+Shift+] / Ctrl+Shift+[）で最前面・最背面へ。ノード上を右クリックしてコンテキストメニューからも変更可（他所クリック・Esc・スクロールで閉じる） |
| 画像を追加 | 「挿入」→「🖼 画像」/ ドラッグ&ドロップ / ペースト（Ctrl+V） |
| 元に戻す | 「編集」→「↶ 元に戻す」/ Ctrl+Z（Mac は Cmd+Z） |
| やり直す | 「編集」→「↷ やり直す」/ Ctrl+Shift+Z または Ctrl+Y（Mac は Cmd+Shift+Z） |
| ズーム | マウスホイール（カーソル位置を中心に拡大縮小、0.1〜5倍） |
| パン（移動） | 右ボタンドラッグ（ノード上でも可）/ 空白部分をドラッグ / Space キーを押しながらドラッグ / 中ボタンドラッグ |
| 表示リセット | 「表示」→「⟲ リセット」（位置・ズームを初期状態に戻す）/「⛶ 全体表示」（全ノードが収まるように表示） |
| 新しいボード | 「ファイル」→「新規」（ボードを空にし、ボード名を「無題のボード」に戻す） |
| 保存 | 「ファイル」→「保存 (.svg)」 |
| 読み込み | 「ファイル」→「開く (.svg)」 |
| リンクを設定 | 右クリック → リンクを設定 / Ctrl+K（Mac は Cmd+K、単一選択時のみ） |
| リンクを開く | ノードをクリック → 表示された URL をクリック（別タブで開く） |

### 未保存の変更について

「新規」と「開く (.svg)」は現在のボードを置き換えます。**最後に .svg へ保存した（または .svg から読み込んだ）時点から内容が変わっている場合は、確認ダイアログが出ます**（「保存して…」「保存せずに…」「キャンセル」の3択）。

ブラウザ内の自動保存（localStorage）は操作のたびに常に最新になるため、この判定には使っていません。判定の対象はノード・コネクタ・ボード名で、表示位置やズームの変更は含みません。

## データ形式

`.svg` ファイルとして保存されます。SVGとして任意のビューアで表示でき、openboardで再度読み込んで編集することもできます。
