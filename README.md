# whiteboard-h2

SVGベースの軽量ホワイトボードツール。ブラウザとElectronデスクトップアプリの両方で動作します。

## 特徴

- ゼロ依存（バニラJS + SVG）
- ブラウザ・Electronどちらでも動作
- ボードを `.svg` ファイルとして保存（SVG + 埋め込みJSONで再編集可能）

## 起動

```bash
npm install      # 初回のみ
npm start        # Electron デスクトップアプリ
npm run serve    # ブラウザ版（http://localhost:8080）
```

## 使い方

| 操作 | 方法 |
|------|------|
| 付箋を追加 | 「+ 付箋」ボタン |
| テキストを追加 | 「T テキスト」ボタン（背景・枠なしのテキストのみのノード。追加直後に編集モードに入り、空のまま確定すると自動で削除される） |
| 移動 | ドラッグ（複数選択時は選択中の全ノードがまとめて移動） |
| サイズ変更 | 選択して四隅・辺のハンドルをドラッグ（Shift で縦横比維持）。付箋は四隅のみで常に縦横比固定。付箋の縦横比はスタイル編集から 1:1 / 3:2 を選択 |
| テキスト編集 | ダブルクリック |
| 文字の配置 | ノードを選択すると出るスタイル編集から、横（左/中央/右）と縦（上/中/下）を設定（付箋・図形の新規作成時は上下左右とも中央） |
| 削除 | クリックで選択 → Delete キー（複数選択時はまとめて削除） |
| 複数選択 | Shift+クリックで追加/解除 / Shift+空白ドラッグで矩形選択 |
| 全選択 | Ctrl+A（Mac は Cmd+A） |
| 選択解除 | Esc |
| コネクタ | 「→ コネクタ」ボタン → ノードを2つクリックして接続（Esc または空白クリックで解除） |
| コネクタ削除 | コネクタをクリックして選択 → Delete キー |
| 重なり順（Z順）の変更 | Ctrl+]（Mac は Cmd+]）で前面へ、Ctrl+[ で背面へ、Shift併用（Ctrl+Shift+] / Ctrl+Shift+[）で最前面・最背面へ。ノード上を右クリックしてコンテキストメニューからも変更可（他所クリック・Esc・スクロールで閉じる） |
| 画像を追加 | 「🖼 画像」ボタン / ドラッグ&ドロップ / ペースト（Ctrl+V） |
| 元に戻す | 「↶ 元に戻す」ボタン / Ctrl+Z（Mac は Cmd+Z） |
| やり直す | 「↷ やり直す」ボタン / Ctrl+Shift+Z または Ctrl+Y（Mac は Cmd+Shift+Z） |
| ズーム | マウスホイール（カーソル位置を中心に拡大縮小、0.1〜5倍） |
| パン（移動） | 右ボタンドラッグ（ノード上でも可）/ 空白部分をドラッグ / Space キーを押しながらドラッグ / 中ボタンドラッグ |
| 表示リセット | 「⟲ リセット」ボタン（位置・ズームを初期状態に戻す） / 「⛶ 全体表示」ボタン（全ノードが収まるように表示） |
| 保存 | 「保存 (.svg)」ボタン |
| 読み込み | 「開く (.svg)」ボタン |
| リンクを設定 | 右クリック → リンクを設定 / Ctrl+K（Mac は Cmd+K、単一選択時のみ） |
| リンクを開く | ノードをクリック → 表示された URL をクリック（別タブで開く） |

## データ形式

`.svg` ファイルとして保存されます。SVGとして任意のビューアで表示でき、openboardで再度読み込んで編集することもできます。

## WSL2 での注意

初回のみ以下のライブラリが必要です：

```bash
sudo apt-get install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libgbm1 libasound2t64 libgtk-3-0 libxss1 libxtst6 libxrandr2
```
