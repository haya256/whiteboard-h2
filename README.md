# whiteboard-h2

SVGベースの軽量ホワイトボードツール。ブラウザとElectronデスクトップアプリの両方で動作します。

## 特徴

- ゼロ依存（バニラJS + SVG）
- ブラウザ・Electronどちらでも動作
- ボードを `.svg` ファイルとして保存（SVG + 埋め込みJSONで再編集可能）。開いたファイルへの上書き保存（Ctrl+S）に対応

## 起動

```bash
npm install      # 初回のみ
npm start        # Electron デスクトップアプリ
npm run serve    # ブラウザ版（http://localhost:8080）
```

サーバーを立てなくても、`index.html` をブラウザで直接開くだけで動作します（ビルド不要・サーバー処理なし）。
ただし自動保存（localStorage）はブラウザが「開いた場所（URL）」ごとに分けて保持するため、`file://` で開いた場合と `http://localhost:8080` で開いた場合ではボードが共有されません。別の場所で開き直すときは .svg で保存して読み込んでください。

## 動作環境

- **推奨: Google Chrome / Microsoft Edge（最新版）**。すべての機能が動作します。
- Firefox / Safari でも動作しますが、以下の機能制限があります。
  - 「開く」「名前を付けて保存」は File System Access API を使ってフォルダの場所を記憶しますが、Firefox / Safari は非対応のため、従来のファイル選択ダイアログとダウンロードに自動で切り替わります（保存先はブラウザのダウンロードフォルダになり、フォルダの記憶はできません）。
  - 同じ理由で、Firefox / Safari では「保存」も開いたファイルへの上書きにはならず、ダウンロードになります。
- スマートフォン・タブレットのタッチ操作は未対応です（マウス操作を前提にしています）。
- データはサーバーに送信されません。自動保存はブラウザ内（localStorage、多くのブラウザで約 5MB）に保持され、大きな画像を多く貼ると上限に達することがあります。その場合は .svg で保存してください。

## ツールバー

用途ごとに5つのグループに分かれています。

| グループ | 内容 |
|------|------|
| ファイル | 新規 / 開く / 保存 / 名前を付けて保存 |
| 編集 | 元に戻す / やり直す |
| 挿入 | 付箋 / 図形（パレット）/ テキスト / 画像 / コネクタ |
| 表示 | ズーム率 / 全体表示 / リセット |
| その他 | 設定（背景の切り替え）/ 使い方（ウェルカム画面を開く） |

ウィンドウの幅が足りないときは、入りきらないボタンが各グループの「⋯」にまとまります（畳まれる順は その他 → 編集 → 表示 → ファイル → 挿入。各グループの左端のボタンは常に残るため、「表示」の左端にあるズーム率はいつでも確認できます）。

## 使い方

| 操作 | 方法 |
|------|------|
| 付箋を追加 | 「挿入」→「+ 付箋」 |
| 図形を追加 | 「挿入」→「◇ 図形」で左に図形パレットが開き、その中の図形をクリックすると追加される（矩形・楕円・ひし形のほか、三角形・六角形・星などの基本図形、端子・書類・円筒などのフローチャート記号、矢印・吹き出し、人・本のアイコンがカテゴリ別に並ぶ）。パレットは続けて置けるよう開いたままになり、開閉状態は次に開いたときも引き継がれる |
| テキストを追加 | 「挿入」→「T テキスト」（背景・枠なしのテキストのみのノード。追加直後に編集モードに入り、空のまま確定すると自動で削除される） |
| 移動 | ドラッグ（複数選択時・グループ選択時は選択中の全ノードがまとめて移動） |
| サイズ変更 | 選択して四隅・辺のハンドルをドラッグ（Shift で縦横比維持）。付箋は四隅のみで常に縦横比固定。付箋の縦横比はスタイル編集から 1:1 / 3:2 を選択 |
| テキスト編集 | ダブルクリック |
| 文字の配置 | ノードを選択すると出るスタイル編集から、横（左/中央/右）と縦（上/中/下）を設定（付箋・図形の新規作成時は上下左右とも中央） |
| 削除 | クリックで選択 → Delete キー（複数選択時はまとめて削除） |
| 複製 | 選択して右クリック → 複製 / Ctrl+D（Mac は Cmd+D）。複製したノードは元の右下24pxに置かれ、そのまま選択される。複数選択なら位置関係を保ったまま、選択ノード同士をつなぐコネクタごと複製される |
| 複数選択 | Shift+クリックで追加/解除 / 空白部分をドラッグで矩形選択（Shift/Ctrl 併用で既存の選択に追加） |
| グループ化 | 2つ以上選択して Ctrl+G（Mac は Cmd+G）/ 右クリック → グループ化。グループは破線の枠で示され、メンバーのどれをクリックしてもグループ全体が選択されて、まとめて移動できる |
| グループ解除 | Ctrl+Shift+G（Mac は Cmd+Shift+G）/ 右クリック → グループ解除。メンバーを1つ選んだ状態でも、そのグループ全体が解散される |
| グループ内の1つだけを選ぶ | グループ全体が選択されている状態でメンバーをクリックすると、そのノード単体の選択に切り替わる（そのままサイズ変更・スタイル編集ができる）。続けて別のメンバーをクリックすると、そのメンバー単体の選択に移る。Esc や空白クリックで抜けると、次のクリックはまたグループ全体の選択に戻る |
| 全選択 | Ctrl+A（Mac は Cmd+A） |
| 選択解除 | Esc |
| コネクタ | 「挿入」→「→ コネクタ」→ ノードを2つクリックして接続（Esc または空白クリックで解除） |
| コネクタ削除 | コネクタをクリックして選択 → Delete キー |
| コネクタの見た目 | コネクタをクリックすると出るスタイル編集から、線種（直線/曲線/直角。新規作成時は曲線）・矢印の向き（なし/終点/始点/両端）・太さ・色を変更 |
| 重なり順（Z順）の変更 | Ctrl+]（Mac は Cmd+]）で前面へ、Ctrl+[ で背面へ、Shift併用（Ctrl+Shift+] / Ctrl+Shift+[）で最前面・最背面へ。ノード上を右クリックしてコンテキストメニューからも変更可（他所クリック・Esc・スクロールで閉じる） |
| 画像を追加 | 「挿入」→「🖼 画像」/ ドラッグ&ドロップ / ペースト（Ctrl+V） |
| 元に戻す | 「編集」→「↶ 元に戻す」/ Ctrl+Z（Mac は Cmd+Z） |
| やり直す | 「編集」→「↷ やり直す」/ Ctrl+Shift+Z または Ctrl+Y（Mac は Cmd+Shift+Z） |
| ズーム | マウスホイール（カーソル位置を中心に拡大縮小、0.1〜5倍） |
| パン（移動） | 右ボタンドラッグ（ノード上でも可）/ Space キーを押しながらドラッグ / 中ボタンドラッグ |
| 表示リセット | 「表示」→「⟲ リセット」（位置・ズームを初期状態に戻す）/「⛶ 全体表示」（全ノードが収まるように表示） |
| 新しいボード | 「ファイル」→「新規」（ボードを空にし、ボード名を「無題のボード」に戻す） |
| 保存（上書き） | 「ファイル」→「保存」/ Ctrl+S（Mac は Cmd+S） |
| 名前を付けて保存 | 「ファイル」→「名前を付けて保存」/ Ctrl+Shift+S（Mac は Cmd+Shift+S） |
| 読み込み | 「ファイル」→「開く」 |
| リンクを設定 | 右クリック → リンクを設定 / Ctrl+K（Mac は Cmd+K、単一選択時のみ） |
| リンクを開く | ノード右上の 🔗 アイコンをクリック（別タブで開く。アイコンにマウスを乗せると URL が出る）/ ノードをクリック → 表示された URL をクリック |
| 設定を開く | 「その他」→「⚙ 設定」 |

### 設定

「その他」→「⚙ 設定」で開きます。設定は**アプリ全体のもの**で、ブラウザ内（localStorage）にボードとは別に保存され、どのボードを開いても同じ設定が使われます。`.svg` には含まれないため、ファイルを渡しても相手の設定は変わりません。

| 項目 | 選択肢 |
|---|---|
| キャンバスの背景 | ドット（既定）/ 宇宙 |

背景は画面に固定で描かれるため、パン・ズームしても動きません。また、**書き出す `.svg` の背景は設定にかかわらず薄いグレー（`#f5f5f8`）のまま**です。

「宇宙」を選ぶと、テキストノードとコネクタの既定色（`#333333`）は暗い背景に埋もれて見えにくくなります。既定色は変えていないので、必要に応じてそれぞれのスタイル編集から明るい色を選んでください。

設定項目を増やすときは `src/settings.js` の `DEFAULTS` に1行足し、`index.html` の設定ダイアログに `.settings-row` を1つ足し、反映したいモジュールから `Settings.subscribe()` します（背景は `src/view.js` の `BACKGROUNDS` がカタログを持ち、選択肢もそこから作られます）。

### 未保存の変更について

「新規」と「開く」は現在のボードを置き換えます。**最後に .svg へ保存した（または .svg から読み込んだ）時点から内容が変わっている場合は、確認ダイアログが出ます**（「保存して…」「保存せずに…」「キャンセル」の3択）。

ブラウザ内の自動保存（localStorage）は操作のたびに常に最新になるため、この判定には使っていません。判定の対象はノード・コネクタ・ボード名で、表示位置やズームの変更は含みません。

### 「保存」と「名前を付けて保存」

- **保存**（Ctrl+S）… 開いているファイルへ確認なしで上書きします。`.svg` から開いた直後は、ブラウザの書き込み許可の確認が1回だけ出ます。
- **名前を付けて保存**（Ctrl+Shift+S）… 保存ダイアログで保存先とファイル名を決めて書き出します。保存後はそのファイルが「保存」の上書き先になります。

### 再読み込み・タブを閉じるとき

内容のあるボードで再読み込みやタブを閉じる操作をすると、確認ダイアログが出ます（ブラウザ標準のダイアログのため、文言と選択肢はブラウザが決めるもので変更できません。ページを一度も操作していない場合はブラウザの仕様でダイアログ自体が出ません）。

再読み込みしてもボードの内容は localStorage から復元されますが、**元に戻す履歴**と**下記のファイルの結びつき**は失われます。

Electron 版（`npm start`）では、同じ場面で `main.js` が独自の確認ダイアログを出します。

### 保存先の記憶について

ファイルとの結びつきは**ページを閉じるまで**です。ボードの内容は localStorage から復元されますが、ファイルハンドルは復元できないため、開き直したあとの最初の「保存」は「名前を付けて保存」と同じ動作になります。

ボード名はファイル名になるため、**ボード名を変更してから「保存」を押すと別名保存の意図とみなし、保存ダイアログが開きます**（元のファイルはそのまま残ります）。

## データ形式

`.svg` ファイルとして保存されます。SVGとして任意のビューアで表示でき、openboardで再度読み込んで編集することもできます。

## 変換スクリプト（任意）

`scripts/` に、画像や Miro のボードから `.svg` を作るための Node スクリプトがあります。**アプリ本体とは独立していて、`index.html` を開くだけの使い方には一切関係しません**（アプリはゼロ依存のままです）。

```bash
node scripts/board-from-spec.js <spec.json>                 # 仕様 JSON から .svg を作る
node scripts/miro-to-spec.js <boardURL|boardID> <spec.json> # Miro のボードから仕様 JSON を作る
```

Miro から取り込むには、`config/miro.json` に `{ "token": "..." }`（`boards:read` 権限のアクセストークン）を置きます。このファイルは公開しないよう .gitignore 済みなので、各自で用意してください。

付箋・図形・テキスト・フレーム・画像・コネクタ（矢印の向き・線種・色・太さ・ラベル）を取り込みます。リンクプレビューはカード風の図形として置き、タイトルと開くためのリンクを持たせます。Miro のステンシルなど API がスタイルを返さない要素は、既定の枠で描いたうえで警告に出します。

REST API v2 が `isSupported: false` で返す要素があるときだけ、補助として旧 v1 API（`/v1/boards/{id}/widgets`）も引きます。リンクプレビューの URL とタイトルは v1 でしか取れないためです。v1 は非推奨なので、応答しなくなったら警告を出してその分だけ諦めて続行します。

### 画像の取り込み

`miro-to-spec.js` の `--images` で、画像をどう取り込むか選べます。

| 値 | 内容 |
|---|---|
| `fit`（既定） | 原寸を取得し、アプリの画像追加と同じ基準（長辺1600px・JPEG 品質0.85・透過があれば PNG）で再エンコードする |
| `original` | 原寸のまま埋め込む。画質は最高だが、自動保存の上限（約5MB）を超えやすい |
| `preview` | Miro が返す長辺120pxのサムネイル。極端に軽いが内容は読めない |
| `none` | 画像を取り込まない |

`fit` には [sharp](https://sharp.pixelplumbing.com/) が必要です。`optionalDependencies` なので `npm install` で一緒に入りますが、環境によってビルドできなくてもインストール全体は失敗しません。sharp が無い場合は警告を出して `original` として動作します。

`.svg` は画像を data URI で持ち、しかも `href` / `xlink:href` / 埋め込み JSON の3か所に入るため、**元画像の約4倍**の大きさになります。自動保存を効かせたい場合は `fit` を使ってください。
