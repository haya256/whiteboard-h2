対応環境

  • Chrome / Edge（最新版）を推奨します。Firefox / Safari でも使えますが、一部の機能に制限があります。
詳細
  • Chrome / Edge では「開く」「名前を付けて保存」のダイアログが前回のフォルダを記憶し、保存先とファイル名をその場で選べます。「保存」は開いているファイルへそのまま上書きします。
  • Firefox / Safari ではこの仕組みが使えないため、従来のファイル選択とダウンロードになります。保存先はブラウザのダウンロードフォルダで、フォルダの記憶はできず、「保存」も上書きではなくダウンロードになります。
  • スマートフォン・タブレットのタッチ操作には対応していません。

基本操作

  • 追加：「挿入」から様々な図形などを設置できます。画像はドラッグ＆ドロップや Ctrl+V でも追加できます。
  • 文字の編集：ノードをダブルクリック。
  • 移動・複数選択：ドラッグで移動、Shift+クリックまたは何もない場所をドラッグ（矩形選択）で複数選択。
  • 削除：選択して Delete。
  • 複製：選択して Ctrl+D、または右クリックメニューの「複製」。
  • つなぐ：「挿入」の「→ コネクタ」を押してから2つのノードをクリック。
  • ズームとパン：マウスホイールでズーム、右ボタンドラッグまたは Space+ドラッグでパン。
  • リンク：右クリックメニューから設定すると、ノード右上に 🔗 が付きます。🔗 をクリックすると別タブで開きます（マウスを乗せると URL を確認できます）。
  • 右クリックメニュー：複製やリンクの設定、重なり順の変更・削除ができます。
  • 保存：Ctrl+S で開いているファイルに上書き保存、Ctrl+Shift+S で名前を付けて保存。
  • 設定：「その他」の「⚙ 設定」からキャンバスの背景（ドット／宇宙）を変えられます。設定はこの端末のブラウザに保存され、どのボードを開いても同じ背景になります。

「宇宙」の背景では、テキストとコネクタの既定の色（濃いグレー）が見えにくくなります。それぞれを選択すると出るスタイル編集から明るい色に変えてください。書き出す .svg の背景は設定にかかわらず薄いグレーのままです。

データはどこに保存される？
  • このボードの内容はサーバーには送信されません。お使いのブラウザの中（localStorage）に自動保存され、同じ端末・同じブラウザで開き直すと復元されます。
  • 別の端末で使う・バックアップする・複数のボードを持つには「ファイル」の「名前を付けて保存」でファイルに書き出してください。「開く」で読み戻せます。書き出した .svg はブラウザでそのまま表示もできます。
  • 一度ファイルに書き出す（または .svg から開く）と、以降は「保存」（Ctrl+S）でそのファイルに上書きできます。この結びつきはページを閉じるまでで、開き直したあとの最初の保存では保存先をもう一度選びます。
  • そのため、内容のあるボードで再読み込み・タブを閉じようとすると確認が出ます。再読み込みしてもボードの内容は残りますが、元に戻す履歴と上のファイルの結びつきは失われます。
  • ブラウザのサイトデータを削除すると自動保存の内容も消えます。大事なボードは .svg でも保存しておいてください。
データ量の目安と制限
  • ブラウザ内の自動保存には容量の上限があります（多くのブラウザで 約5MB）。文字や図形だけのボードなら気にする必要はほとんどありません。
  • 容量を使うのは主に画像です。画像は追加時に長辺1600px以下へ自動で縮小されますが、それでも1枚あたり数百KBになるため、目安として10枚前後で上限に達することがあります。
  • 上限を超えると画面下に「自動保存できません」と通知が出ます。編集中の内容は消えませんが、ページを閉じると失われるので、その場合は「名前を付けて保存」でファイルに書き出してください。.svg ファイルにはこの上限はありません（画像を含むぶんファイルは大きくなります）。
  • 大きなボードは1つにまとめず、テーマごとに .svg を分けて管理するのがおすすめです。
